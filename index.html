Strictly Minimal Scope

Requests only https://www.googleapis.com/auth/youtube.upload and invokes a single endpoint (videos.insert) once per day (~1,600 units / 10,000 daily default quota).

Private Owner-Only Access

Not open to third-party registrations or public sign-ins. Authorized exclusively by the channel owner using OAuth 2.0 Desktop flow with encrypted secret storage.

Zero Data Storage

Does not collect, scrape, cache, or share any YouTube user data, comments, or channel analytics. Access can be revoked anytime via Google Security Settings.

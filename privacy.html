1. Use of YouTube API Services

Spawn In Vice Automation uses YouTube API Services strictly as a private, single-owner internal creator tool to upload original short-form gaming videos (YouTube Shorts) to the owner's own channel (@spawninvice).

The application requests only the minimal OAuth 2.0 scope https://www.googleapis.com/auth/youtube.upload and calls only the videos.insert endpoint (1 scheduled upload per day).

By using this application, you agree to be bound by the YouTube Terms of Service: https://www.youtube.com/t/terms

2. Google Privacy Policy

All data processed through YouTube API Services is subject to Google's Privacy Policy. You can review how Google collects, uses, and protects information at:

Google Privacy Policy:
https://policies.google.com/privacy

Spawn In Vice Automation adheres to the Google API Services User Data Policy and the YouTube API Services Developer Policies. No API data is ever sold, transferred, or disclosed to external third parties.

3. Information Accessed, Stored & Shared

  • Single Authorized Owner Only: This internal script is not publicly accessible and does not accept third-party user logins or accounts.
  • No YouTube Data Collection or Caching: The client does not read, scrape, store, or cache any YouTube user profiles, comments, subscriptions, analytics, or third-party channel data.
  • OAuth Credentials Only: Only the channel owner's encrypted OAuth 2.0 refresh token is stored securely in private repository secrets to authenticate daily videos.insert requests.
  • No Cookies or Tracking: This site and tool do not place advertising cookies or third-party trackers on any user's device.

4. Revoking Access & Data Deletion Policy

Revoke Access Anytime: In addition to our internal removal procedure, you may revoke Spawn In Vice Automation's access to your Google account and YouTube channel at any time via the Google Security Settings page:

https://security.google.com/settings/security/permissions

Data Deletion: Because no YouTube API user data is stored or cached, revoking access immediately terminates API access. To request permanent deletion of any stored OAuth configuration or credentials, email spawninvice@gmail.com; all credential secrets are permanently purged within 24 hours.
